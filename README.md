# Beyond the Nodes — starter website

A responsive bilingual (English/Arabic) lymphoma awareness website built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and structure
- `style.css` — visual design and responsive layout
- `script.js` — language toggle and small interactions

## Publish with GitHub Pages
1. Sign in to GitHub and create a new repository. For example: `beyond-the-nodes`.
2. For the simplest setup, choose **Public** and create the repository.
3. Upload `index.html`, `style.css`, and `script.js` to the repository's root (top level), not inside another folder.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/(root)`, then click **Save**.
7. Wait a few minutes and revisit the Pages settings for the published URL.
8. Test the site on a phone before creating a QR code for the final URL.

## Before public launch
- Have a qualified clinician review the medical wording and references.
- Add the date of medical review and update sources as needed.
- Add only case details that are verified, de-identified, and approved for educational publication.
- Do not upload identifiable patient records, scans, or pathology images without appropriate authorization.
- Test the Arabic layout, all links, keyboard navigation, and phone screen sizes.
- Google Fonts requires an internet connection; the site content and styling otherwise use local files.

This is an educational awareness prototype, not a diagnostic tool or medical advice service.
